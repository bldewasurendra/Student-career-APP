# 🎓 Student Career Guide App

[![Flutter](https://img.shields.io/badge/Flutter-%2302569B.svg?style=flat&logo=Flutter&logoColor=white)](https://flutter.dev/)
[![Firebase](https://img.shields.io/badge/Firebase-%23039BE5.svg?style=flat&logo=Firebase&logoColor=white)](https://firebase.google.com/)
[![Dart](https://img.shields.io/badge/Dart-%230175C2.svg?style=flat&logo=Dart&logoColor=white)](https://dart.dev/)

A modern, feature-rich career guidance application built with **Flutter** and **Firebase**. This app serves as a digital mentor for students and graduates, helping them navigate the complex path from education to a successful career.

---

## 🌟 Key Features

### 🔐 Advanced Authentication
- **Secure Login & Registration** using Firebase.
- **Google Sign-In Integration** for a seamless user experience.
- **Role-based Access:** Restricted Admin Dashboard for content management.

### 💼 Career Opportunities (Real-time)
- **Jobs & Internships:** Stay updated with the latest industry openings.
- **Higher Studies:** Discover Masters and PhD programs worldwide.
- **Study Abroad:** Dedicated guidance for international education paths.
- *All data is synced in real-time using Cloud Firestore.*

### 📄 Smart CV Builder & ATS Checker
- **PDF Generation:** Create a professional CV by filling in your details.
- **ATS Checker:** Real-time analysis of your CV's "ATS friendliness" with a dynamic scoring system and improvement tips.
- **PDF Preview & Print:** Instantly preview or download your CV as a high-quality PDF.

### 📚 Learning & Guides
- **CV Writing Guide:** Step-by-step instructions and video tutorials.
- **Portfolio Guide:** Expert advice on documenting projects and choosing platforms like GitHub and Behance.
- **Higher Studies Guide:** Comparison between local and international paths with a full preparation checklist.

---

## 🛠️ Tech Stack & Libraries

- **Framework:** Flutter (Dart)
- **Backend:** Firebase (Authentication, Firestore)
- **PDF Engine:** `pdf` & `printing`
- **Video:** `youtube_player_flutter`
- **Design:** Modern Dark Theme, Google Fonts, Custom Animated Splash Screen

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/student-career-guide-app.git
   ```
2. **Install dependencies:**
   ```bash
   flutter pub get
   ```
3. **Firebase Setup:**
   - Create a project in the [Firebase Console](https://console.firebase.google.com/).
   - Add an Android app and download `google-services.json`.
   - Place it in `android/app/`.
4. **Run the app:**
   ```bash
   flutter run
   ```
